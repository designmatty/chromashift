# Security policy

## Supported releases

Only the latest release of ChromaShift receives security fixes. Older releases
are unsupported.

## Reporting a vulnerability

Report a suspected vulnerability through GitHub's
[private vulnerability reporting](https://github.com/designmatty/chromashift/security/advisories/new).
Do not include sensitive details in a public issue.

Maintaining this project does not come with a response or resolution deadline.
A report may be declined, closed, or left unresolved.
