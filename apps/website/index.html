FAQ

How does ChromaShift work?+

When you switch to an app or game, ChromaShift applies the profile you assigned to that app, with separate color settings for each display. Apps without their own profile use the Default profile.

You can also pick a profile yourself from the app, mini panel, tray, or a keyboard shortcut.

Is ChromaShift safe with VAC and other anti-cheat software?+

ChromaShift is built to stay out of your games. ChromaShift never injects code, reads or writes game memory, hooks rendering, or modifies game files.

ChromaShift only checks which program is in the foreground, using limited access that can’t read the program’s memory. Color changes go through the same Windows and NVIDIA or AMD driver settings that GPU control panels use.

No anti-cheat vendor has certified or endorsed ChromaShift.

Which Windows versions and GPUs are supported?+

ChromaShift runs on 64-bit (x64) Windows 11. NVIDIA GPUs are tested on real hardware. AMD GPUs are supported through AMD’s ADLX API but haven’t been tested on an AMD-driven display yet. Intel and other GPUs are recognized, but ChromaShift has no vendor-specific color support for them.

While HDR is on, ChromaShift holds back gamma adjustments that only work in SDR.

What happens when I pause or close ChromaShift?+

Both return your displays to how they were before ChromaShift changed them. Pausing restores your original settings, then stops switching profiles until you resume. Closing restores every connected display before the app exits. If a display can't be restored, ChromaShift stays open instead of leaving that display changed, so the restore can be retried.

Does ChromaShift collect data or require an account?+

No. ChromaShift needs no account and has no telemetry, analytics, or network requests. Your profiles and preferences stay on your PC.

This website is separate. chromashift.io uses Cloudflare Web Analytics for aggregate, cookie-free visitor statistics, and the download button asks GitHub for the newest release.
