Everything it does, briefly.

  • Switches automatically

    Alt-tab into a game and its profile applies. Leave it and the next match takes over.

  • One profile, every display

    Each monitor gets its own values. Leave one out and it stays exactly as it was.

  • Restores what it found

    Your original settings are captured first, and given back on pause, exit, or shortcut.

  • Six color controls

    Brightness, contrast, gamma, saturation, hue, and AMD color temperature where supported.

  • Reachable anywhere

    Mini panel, tray, and global shortcuts pick a profile without opening the app.

  • Nothing leaves your PC

    No account, no telemetry, no network requests. MIT licensed.

FAQ

How does it work?+

ChromaShift watches which application owns the foreground window, resolves the profile assigned to it, and changes the supported display settings through Windows and GPU-driver APIs. You can also select a profile yourself from the app, mini panel, tray, or a shortcut.

Is it safe with VAC and other anti-cheat software?+

Yes. ChromaShift reads which application is in the foreground, then changes display settings through standard Windows and NVIDIA or AMD driver APIs — the same kinds of settings exposed in the GPU control panels. It does not inject DLLs, read or write game memory, hook rendering, or modify game files.

Identifying the foreground executable uses query-only process access; ChromaShift does not inspect process memory. No anti-cheat vendor certifies or endorses it.

Which Windows versions and GPUs are supported?+

Windows 11 x64. NVIDIA behavior is verified on real hardware. AMD support is implemented through AMD ADLX but is not yet verified on an AMD-driven display. Intel and unknown adapters are detected without a vendor-specific color provider, and ChromaShift defers incompatible SDR gamma behavior while HDR is active.

What happens when I pause or close it?+

Pausing restores your displays first and only then stops applying profiles. Closing normally also requires your connected displays to be restored before it exits. If a restore genuinely fails, ChromaShift stays open so it can try again.

Does it collect data or require an account?+

No. The application requires no account and has no telemetry, analytics, or outbound network requests. Profiles and preferences stay on your computer.

This website is separate: chromashift.io uses Cloudflare Web Analytics for aggregate, cookie-free statistics.
